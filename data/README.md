# Data Dictionary

Synthetic dataset for a case study: an AI operations audit of a mid-sized third-party logistics (3PL) provider in the Kanto region of Japan (about 60 office staff). Period: November 2025 to October 2026. All data is generated by `src/generate_data.py` (fixed seed, reproducible).

| File | Rows | Description |
|---|---|---|
| `employees.csv` | 60 | Staff, division, role, loaded hourly cost (JPY) |
| `time_logs.csv` | ~166k | Time-tracking entries per work block (intentionally dirty) |
| `cs_tickets.csv` | 26,000 | Customer service emails/tickets with free text |
| `shipping_documents.csv` | 41,000 | Shipping documents keyed manually into the WMS |
| `carrier_invoice_lines.csv` | 34,000 | Carrier invoice lines vs expected contract rates |
| `employee_survey.csv` | ~54 | Survey: what staff *think* their biggest time drains are |

## time_logs.csv
| Column | Description |
|---|---|
| log_id | Entry ID |
| employee_id | FK to employees |
| work_date | Date (mixed `YYYY-MM-DD` / `YYYY/MM/DD`) |
| task_type | Task category (inconsistent casing/whitespace) |
| system | Tool used for the task |
| items_handled | Number of items in the block (emails, documents, lines) |
| duration_min | Minutes spent (has missing, negative and >10h values) |

Known data quality issues to clean: duplicate submissions (~1.2%), inconsistent task labels (~6%), missing durations (~0.6%), negative durations, timers left running (600–1,400 min), mixed date formats.

## cs_tickets.csv
`ticket_id, created_at, channel, customer_segment, message_text, category, handling_min, first_response_min, reopened` (~4% of tickets have no category label).

## shipping_documents.csv
`doc_id, received_date, doc_type, source_format, pages, fields_keyed, entry_min, field_errors, rework_min, keyed_by`

## carrier_invoice_lines.csv
`line_id, invoice_month, carrier, shipment_ref, expected_amount_jpy, billed_amount_jpy, mismatch_reason, check_min, dispute_min, recovered`

## employee_survey.csv
`employee_id, division, biggest_time_drain_1..3, est_hours_per_week_on_drain_1, open_to_ai_tools_1to5, comment`
